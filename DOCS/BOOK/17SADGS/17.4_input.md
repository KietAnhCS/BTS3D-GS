# INPUT 17.4 — Multiview consistency: high/mid/low ratio

Nguồn: `SADGS/utils/freq_utils.py:395-409`, `SADGS/train.py:335-353`. Văn bản gốc: mục 17.4 (dòng 585-673).

## Công thức phân loại + ngưỡng

`is_high = [eta_max > tau_high=1.0]`, `is_low = [eta_max <= tau_low=0.1]`, còn lại là mid.
Bộ đếm cộng dồn qua nhiều vòng (mỗi 10 iter): `eta_high_count[i]`, `eta_mid_count[i]`, `eta_low_count[i]`, `accum_view_count[i]`.

`high_ratio_i = eta_high_count_i / accum_view_count_i`
`low_ratio_i = eta_low_count_i / accum_view_count_i`

`split_mask_i = [high_ratio_i > tau_split=0.8] AND [||g_bar_i|| >= 1e-5]`
`prune_mask_i = [low_ratio_i > tau_prune=0.8] AND [accum_view_count_i > 0]`

`tau_split = tau_prune = 0.8` (`split_ratio_threshold`, `prune_ratio_threshold`, `arguments/__init__.py:148-149`) — chỉ split nếu Gaussian bị flag "under-resolved" trong >80% số lần nhìn thấy, không phải 1 view lệch.
