# INPUT 17.2 — Multiscale structure tensor (v1 vs v2)

Nguồn: `SADGS/utils/loss_utils.py:232-387`. Văn bản gốc: mục 17.2 (dòng 188-355).
Tham số mặc định: `st_levels=4`, `st_mode="v1"`, `octave_step=1.5`, `power_factor=3.0` (`SADGS/arguments/__init__.py:120-121`).

## Vòng lặp octave (chung v1/v2)

- `sigma_i = sigma_0 * r^i`, `f_i = 1/r^i` (r = octave_step = 1.5).
- **Band response** (kiểu Difference-of-Gaussian): `R_i = ||I_smooth^(i-1) - I_smooth^(i)||_2` theo kênh màu.
- **Trọng số theo năng lượng**: `w_i = R_i^p` (p = power_factor = 3.0).
- **Gộp có trọng số** (chuẩn hoá trace trước khi gộp):
  `(Sxx_hat, Sxy_hat, Syy_hat) = sum_i[ w_i * f_i^2 * (Sxx_i, Sxy_i, Syy_i)/tr_i ] / sum_i(w_i)`, với `tr_i = Sxx_i+Syy_i+1e-6`.
  → mỗi octave chỉ đóng góp **hướng** (chuẩn hoá vết=1), **độ lớn** do `f_i^2` áp đặt.

## v1 vs v2 — khác nhau đúng ở đâu

| | v1 | v2 |
|---|---|---|
| Structure tensor mỗi octave | Tính 1 lần ở octave 0 (`base_st`), các octave sau chỉ làm mờ lại bằng rho_i=3*sigma_i | Tính lại structure tensor mới tại MỖI octave trên ảnh đã mờ đúng sigma_i |
| Chi phí | 1× Sobel + L× blur trên tensor S | L× Sobel + L× blur trên ảnh |
| Số lần gọi lý thuyết | #Sobel_v1 = 3 (cố định) | #Sobel_v2 = 3L |
| Docstring | "Improved Multi-scale" | "True Multi-scale" |

Mặc định `st_mode="v1"` (rẻ hơn, dùng làm tín hiệu gate, không cần chính xác tuyệt đối).

## Ba thực nghiệm đào sâu (script `deep17b_multiscale.py`, ảnh crop thật `DOCS/assets/samples_drjohnson.png` box `(924,381)-(1365,671)`, tủ sách gỗ + cửa kính mullion)

2. **Độ nhạy r (octave_step) và p (power_factor)** — lưới 3×3, r∈{1.2,1.5,2.0}×p∈{1,3,6}: hàng r=1.5, mean_tr giảm 0.4595→0.4072→0.0739 khi p=1→3→6 (winner-take-all); cột p=1, mean_tr giảm 0.7473→0.4595→0.2555 khi r=1.2→1.5→2.0. Ở p=6, cả 3 giá trị r cho bản đồ gần giống hệt nhau về cấu trúc không gian (mean_tr chênh <0.5%).
3. **Kiểm chứng đẳng thức trace**: `tr(S_hat) ≈ sum(w_i*f_i^2)/sum(w_i)` không cần biết Sxx_i,Syy_i cụ thể — residual mean|residual|=3.7e-4 toàn ảnh, max|residual|=4.0e-2 tại vùng phẳng/tối (do epsilon=1e-6 không còn "không đáng kể" khi tr_i nhỏ).
