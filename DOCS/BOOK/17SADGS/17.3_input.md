# INPUT 17.3 — η: so screen-space extent với bước sóng texture cục bộ

Nguồn: `SADGS/utils/freq_utils.py:116-418`, hàm `update_freq_stats_online` (chạy mỗi 10 vòng, `train.py:275`).

## Bước A — chiếu 3 trục scale Gaussian lên màn hình (`compute_projected_axes_subset`, freq_utils.py:116-178)

`J = [[fx/z, 0, -fx*x/z^2],[0, fy/z, -fy*y/z^2]]` (Jacobian phối cảnh tuyến tính hoá, kiểu EWA splatting)
`axes_cam = (R_view * R_i) * diag(s)`, `axes_2D = J * axes_cam` → shape `[N,3,2]`.
Độ dài mỗi trục chiếu: `l_k = sqrt(u_k^2 + v_k^2 + 1e-8)`, k ∈ {x,y,z}.

## Bước B — lấy mẫu structure tensor tại vị trí Gaussian, jitter Cholesky (freq_utils.py:257-292)

Thay vì lấy mẫu đúng tâm mu', lấy mẫu tại điểm ngẫu nhiên trong ellipsoid 1σ:
`L = [[sqrt(sigma_xx), 0],[sigma_xy/sqrt(sigma_xx), sqrt(sigma_yy - sigma_xy^2/sigma_xx)]]`
`(dx,dy) = L·(eps1,eps2)`, eps~N(0,1) → sample tại `mu' + (dx,dy)`.
Lý do: một Gaussian to có thể phủ cả cạnh và vùng phẳng; lấy mẫu ngẫu nhiên + cộng dồn qua nhiều vòng giảm thiên lệch do luôn trúng đúng tâm hình học.

## Bước C — hai công thức η (`eta_compute_mode`, mặc định "wavelength")

**Mode "wavelength"** (freq_utils.py:313-348):
`lambda1 = (Sxx+Syy)/2 + sqrt(((Sxx+Syy)/2)^2 - (Sxx*Syy - Sxy^2))`, `w_min = 1/(sqrt(lambda1)+1e-5)`
`eta_k = l_k / w_min` — không phân biệt hướng trục, chỉ nhìn lambda1 vô hướng.

**Mode "projection"** (freq_utils.py:350-373):
`eta_k = sqrt(Sxx*u_k^2 + 2*Sxy*u_k*v_k + Syy*v_k^2)` — dạng toàn phương a_k^T S a_k, đo đúng theo hướng trục k.

Trọng số transmittance: `w_valid = 1` (BUG — comment nói "Weight by Transmittance" nhưng code chỉ nhân với 1, chưa dùng `max_transmittance` thật). `eta_total = sum_k(eta_k * w_valid)`.
