# INPUT 17.1 — Structure tensor (Di Zenzo, đa kênh RGB)

Nguồn: `SADGS/utils/loss_utils.py:170-230`, hàm `get_structure_tensor_torch(image_tensor, sigma=1.0, rho=1.0)`.
Văn bản gốc: `DOCS/BOOK/17-sadgs-structure-aware-densification.md`, mục 17.1 (dòng 71-186).

## 5 bước công thức (theo đúng thứ tự code chạy)

1. **Làm mờ trước**: `I_smooth = G_sigma * I`, kernel size `k = 2*ceil(4*sigma)+1`.
2. **Sobel theo từng kênh** (conv2d, `groups=C`): `I_x = Sx * I_smooth`, `I_y = Sy * I_smooth`.
3. **Tích và cộng dồn 3 kênh (Di Zenzo)**: `Ixx = sum_ch(I_x^2)`, `Ixy = sum_ch(I_x*I_y)`, `Iyy = sum_ch(I_y^2)`.
   - Lý do cộng RGB thay vì luminance: cạnh iso-luminant có gradient luminance ≈ 0 nhưng gradient từng kênh khác 0.
4. **Tích hợp cửa sổ**: `Sxx = G_rho * Ixx`, `Sxy = G_rho * Ixy`, `Syy = G_rho * Iyy` (rho khác sigma ở bước 1).
5. **Chuẩn hoá theo batch**: chia cho `max_batch(Sxx+Syy) + 1e-6`.

Kết quả: ma trận đối xứng 2×2 tại mỗi pixel `S(x) = [[Sxx, Sxy],[Sxy, Syy]]`; trị riêng lớn nhất λ1 = năng lượng tần số cao nhất tại điểm đó theo bất kỳ hướng nào (dùng lại ở 17.3).

## Trải qua 5 bước

**Bước 1 — làm mờ G_σ=1:**
Cạnh nhị phân (0/10) đã "tãi" ra mượt, ví dụ pixel (3,3) từ 10 → **6.41**.

**Bước 2 — Sobel Ix, Iy (cùng giá trị cho cả 3 kênh vì ảnh xám):**
Tại pixel (3,3): **Ix = -18.28**, **Iy = -18.28** (bằng nhau vì cạnh chéo 45° đối xứng).

**Bước 3 — Di Zenzo (cộng bình phương 3 kênh):**
Tại (3,3): **Ixx = 1002.77**, **Ixy = 1002.77**, **Iyy = 1002.77** (bằng nhau hệt, đúng vì đối xứng chéo).

**Bước 4 — tích hợp G_ρ=1 → structure tensor + trị riêng:**
Sau khi làm mượt không gian, tại pixel **(y=3, x=3)** — ngay trên đường biên:

| Đại lượng | Giá trị |
|---|---|
| Sxx | 673.15 |
| Sxy | 662.32 |
| Syy | 673.15 |
| tr = Sxx+Syy | 1346.31 |
| det = Sxx·Syy − Sxy² | 14464.37 |
| **λ1** | **1335.48** |
| **λ2** | **10.83** |
| **η = √(λ1/λ2)** | **11.10** |

→ Khác với ví dụ cạnh thẳng lần trước (λ2 = 0, η = ∞), lần này **λ2 > 0** thật sự vì cạnh chéo có một chút biến thiên theo cả hai hướng, cho ra **η hữu hạn = 11.10** — một con số cụ thể mà mục 17.3 có thể so sánh với ngưỡng để quyết định densify hay không.

**Bước 5 — chuẩn hoá batch:**
`norm_factor = max(Sxx+Syy) = 1346.31`
→ Sxx tại (3,3) sau chuẩn hoá = 673.15 / 1346.31 = **0.500** (đúng bằng 50%, vì đây chính là điểm max trace).

## Nhìn toàn cảnh bản đồ λ1 và η

Nhìn ma trận `lambda1` cuối cùng, giá trị lớn nhất (1335.48) rơi đúng vào pixel (3,3) — **ngay trên đường biên chéo**, đúng như kỳ vọng: đó là nơi "năng lượng cạnh" mạnh nhất. Còn ma trận `eta` cho thấy giá trị cao nhất (~18.78) nằm ở góc trên/dưới của đường biên (nơi cạnh sắc và ít bị pha trộn theo hướng vuông góc), thấp dần về phía xa cạnh — đúng ý nghĩa: **η cao = anisotropy mạnh = cạnh rõ, một hướng**, **η thấp = đẳng hướng = vùng phẳng hoặc góc phức tạp**.
